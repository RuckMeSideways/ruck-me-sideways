# Ruck Me Sideways — Free Rugby Analysis PWA

Mobile-first PWA. No paid API key required. Uses the public seanyboi/rugbydata GitHub repository as the free-data source/index and supports demo/manual JSON when the repository structure cannot be queried directly from the browser.

## Install on Android
Host this folder over HTTPS (GitHub Pages, Cloudflare Pages, Netlify, etc.), open the URL in Chrome, then choose **Install app** / **Add to Home screen**.

## Free data source
https://github.com/seanyboi/rugbydata

The upstream project states that its data powers rugbypy and is updated daily.
