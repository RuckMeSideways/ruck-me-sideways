🚀 Publish directly to GitHub

Skip the copy/paste - commit the new matches straight to your repo. Requires a GitHub access token (see below for how to create one safely). The token is never saved anywhere except your browser's session storage if you tick "remember," and even then only until you close the tab.

Getting a token (do this once):
1. On GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens
2. Generate new token, give it a name like "Ruck Me Sideways form"
3. Set an expiry (30-90 days is plenty)
4. Under "Repository access," choose "Only select repositories" and pick just ruck-me-sideways
5. Under "Permissions," find "Contents" and set it to "Read and write" - leave everything else as No access
6. Generate, copy the token, paste it above (it won't be shown again by GitHub)
